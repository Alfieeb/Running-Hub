# Running Hub

A small Python terminal app for tracking runs, checking fitness stats, and comparing progress with friends.

## Planned features

- Add, view, and remove saved runs
- Calculate BMI
- See running totals and weekly distance
- Compare weekly distances on a leaderboard

## Project files

- `main.py` — starts the app and displays the menu
- `runs.py` — run-related features
- `runs.json` — saved run data (created when run tracking is added)

## Requirements

- Python 3

## How to run

From the project folder, run:

```bash
python3 main.py
